# Library Management System — Full-Stack Project

Spring Boot + MySQL backend, React + Vite frontend.

## Features
- Books CRUD, search and pagination
- Students CRUD, search and pagination
- Issue and return books
- Admin login with BCrypt and JWT authentication
- Dashboard statistics
- Responsive React frontend
- MySQL database integration
- REST API with Spring Boot
- Postman API collection
- Automated unit tests

## Technology Stack
- Java 21
- Spring Boot
- Spring Data JPA / Hibernate
- MySQL 8
- React
- Vite
- Axios
- Maven
- JWT Authentication
